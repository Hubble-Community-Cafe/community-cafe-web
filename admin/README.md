# admin

React admin app (Azure AD / Entra login) where staff/board manage **both** bars. A bar selector
scopes per-bar content; shared content (current board) is edited once. Manages the 5 CMS modules
(menu, opening hours, events, board, vacancies) plus media uploads and form submissions.

_Scaffolded in a later step (Vite + React + TS + MSAL, consuming `shared-web`)._
